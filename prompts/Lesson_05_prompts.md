# Lesson 05 — 프롬프트

## 프롬프트 1

`specs/roadmap.md`에서 다음 단계(phase)를 확인하여 브랜치를 생성하고, 해당 기능(feature)의 명세에 대해 저에게 문의하세요.
다음 항목을 생성하세요:
- 이 기능 작업을 위해 `specs` 하위에 `YYYY-MM-DD-feature-name` 형태의 새 디렉터리 생성
- 해당 디렉터리 내에 다음 파일 생성:
- `plan.md`: 번호가 매겨진 작업 그룹(task groups)의 형태로 작성
- `requirements.md`: 범위, 결정 사항, 배경 정보(context) 기술
- `validation.md`: 구현 성공 여부 및 병합(merge) 가능 여부 확인 방법 기술

참고 자료: `specs/mission.md` 및 `specs/tech-stack.md`를 지침으로 활용하세요.

중요: 디스크에 파일을 작성하기 전에 반드시 `AskUserQuestion` 도구를 사용하여 위 3가지 항목에 대해 질문해야 합니다.
